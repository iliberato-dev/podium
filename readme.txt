DESCRIÇÃO DO PROJETO:

O site da Podium Inteligência Empresarial foi adaptado a partir de um template base para apresentar
a identidade da consultoria de forma institucional e objetiva.

O projeto destaca:

- Quem somos
- Missão
- Propósito
- Valores
- Serviços e soluções
- Método de atuação
- Contato institucional

A proposta é comunicar, de forma clara e visualmente consistente, como a Podium transforma dados,
estratégia e execução em crescimento sólido para empresas.

==================================================================================================

BASE UTILIZADA:

Template original Hudson, customizado para a marca Podium Inteligência Empresarial.
